# 商品已售成本核对

2026-11-04 用户确认采用移动加权平均，每次入库后更新成本。记账本的“已售成本核对”和原入库采购资料均可进入核对页。

## 复用与权限

沿用 038 原库存流水、057 归属余额、062 SKU、063 入库/发货单、064 原发货明细关联退货、065 最新采购成本版本与原支出引用。不新增库存余额或收货动作，不修改数量、原单据或财务记录；原代码包的服务端未找到可直接复用的移动成本核算。新增服务只读重算，无新迁移或云端写入。

查看需要 finance。普通员工和仅 resources 授权管理员无法读成本接口。原数量接口继续隔离采购价格。原采购及库存详情跳转分别沿用其现有权限。

## 重算规则

- 一个 SKU 的公共与各店铺归属共用成本池。内部双向调拨、旧总库存分账生成的期初复制流水不重复计入数量或成本。
- 业务单按业务日期、同日原登记时间（保留微秒）重放；旧手工流水按北京时间登记日。遇到同刻不同类型的非零业务或日期导致负库存，标记待核对，不猜测顺序。
- 入库使用最新采购版本的逐行货款与附加费。新库存金额 = 原库存金额 + 本次入库金额；平均成本 = 新库存金额 / 新库存数量。采购日期与付款日期不替代实际入库日期。
- 发货按出库前平均成本扣减库存。可重售退货按原发货明细成本比例回冲，进入退货业务月份并重新计算库存平均价。跨月退货不强行抵减本月发货数量，净回冲可为负数。
- 转样品、其他出库和盘亏按当时平均成本扣库存，单独展示，不并入已售成本，也不自动生成费用归属。盘盈没有采购依据时保持成本未知。
- 期初非零、未登记采购金额的入库和找不到已知原发货成本的退货都保持未知；真正免费且明确为零的采购可以计算。未知库存耗尽到零后可以从后续有依据的入库重新建立成本；旧未知发货的退货仍保持未知。
- 内部使用整数分和约分后的任意精度分数，展示时四舍五入到分，不把显示舍入值带回下一笔计算。
- 选择月份时重放此前全部来源，展示当月发货、退货、变动和截至月末的已登记余额。最新采购版本变化会重算历史动态结果；关联支出版本变化提示核对。所选月份未来部分同样仅包含已登记记录。
