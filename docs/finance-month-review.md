# 月度来源完整性检查

记账本及经营总览新增“月度来源检查”。本轮只检查已录来源、集中列出原记录待补项；不生成新账目、银行余额、月结快照或锁定。

## 先确认该月经营店铺

每月手工确认实际经营店铺范围，默认不勾选、不根据当前启用状态推断历史。已停用店铺仍可选择；可明确确认空范围。所有修改需说明依据，保留版本、店铺名称快照、操作者和时间。未确认范围、范围内店铺缺收入、已有业务店铺落在范围外均列为经营依据待补，不自动补零或扩大范围。

范围仅用于检查遗漏，不改动原经营总览的纳入逻辑、不改收入、不分摊公共费用。将来的锁定需要同时保存范围与完整来源快照，不能直接以当前总览数值作为已月结利润。

## 沿用原有来源与口径

- 经营来源与总览共用同一查询及计算函数；新增无条数截断的待核对项收集，原总览的前50项摘要保持。
- 收入仍手工确认平台月度可提现金额，允许明确零或负数；撤回算未确认。佣金、客户退款等平台已扣项目不再扣，商品、代发和工作室成本另算。
- 汇总支出归属/用途缺失、商品已售成本缺依据、代发参考成本或重复来源、包材及样品损耗待归属、原成本引用有新版本等既有问题。同一原问题去重；未归属支出引发的每店派生提示不重复展示。
- 另查截至该月仍持有的库存与样品资产。原库存成本缺失或引用变更时提供原采购、期初或库存成本入口。完全清空的库存池不保留“月末持有资产”问题，新入库沿用移动加权平均；当月损耗和已售成本缺口仍由原规则独立检查。借还样品不消耗资产。
- 资金对应沿用原实际流水的来源版本及累计对应金额。跨月到账/付款仍检查其原收入或支出月份，支出日期更正前后月份均可发现旧对应待重核；作废流水不参与。收入与已录资金差额只提示，不自动生成费用、欠款或收入调整。
- 垫付沿用原支出、结算和报销记录。显示当前累计余额，明确跨月、非所选月末余额，不将混合月份结算虚拟分摊到单笔或当月。

类别为月份、范围、收入、经营成本、库存与样品资产、实际资金对应、累计待报销。经营依据与资金/报销提示分开计数，支持类别、处理类型及50项分页；计数基于全部记录，不随当前页截断。当前或未来月份保留“月份尚未结束”提示（按上海日期）。

## 权限与保存

全部读取与范围维护需要实时财务授权，不要求额外人员/薪资授权。原数量记录和个人薪资不被复制到新的报表接口。范围写入使用当前版本、按月串行、操作者私有请求回执、幂等重试、追加历史与事务回滚；第077项迁移只增加范围表，001–033原迁移校验保持。只读预览仅增加声明的GET入口，不转发保存或私人恢复回执。

## 检查边界

`recordedSourcesReady` 只表示当前检查未发现已录来源的经营依据缺口，不是可月结、已锁定或已完成银行对账。未录入的水电、工资、运费等不能自动发现，仍需人工核对覆盖。资产未自动折旧，不创建完整资产负债表；资金无期初账户余额；报销不提供单笔支出精确核销。

后续078已增加[月结快照、锁定和重新开放机制](finance-month-closures.md)；本检查仍只检查已录来源，不单独锁定。实际页面操作及桌面UI集中修整仍按用户要求暂停，云端未写入、迁移或部署。

## 本机验证

新增真实后端检查覆盖历史停用店铺、无来源店铺漏填收入、零/负收入及撤回、范围外业务、成本问题超过50项、未消耗库存/样品资产、已清空成本池、原成本引用更正、跨月资金及日期变更、原报销累计余额、范围并发/幂等/私有回执/回滚、权限撤销、CSRF、追加历史。前端验证覆盖数据契约、缺失值、精确差额、原入口、范围编辑与只读预览隔离。

本轮完整回归通过：218项前端/接口契约、339项真实后端检查，共557项。第077项迁移完成原001–033基线的兼容升级和重复执行验证；实际页面未做浏览器操作验收。
