# 账号开通与密码重置（2026-11-03）

管理员在“用户与角色权限”中开通账号。继续使用原用户名、admin/employee 角色与原密码散列，不开放公开注册，不创建默认密码。用户名为 3 至 64 位小写字母/数字/点/下划线/短横线，首位字母或数字；密码沿用原规则，12 至 128 字符，不自动去除首尾空格。

开通时可选择一个尚未关联登录的有效原成员；新账号、绑定、成员版本与身份事件同事务保存。可暂不关联，之后在团队成员页面绑定已有账号。已绑定、停用、版本变化的成员拒绝覆盖，不重复创建人员档案。

重置入口用于其他账号。新密码填写两次，必须提供操作原因；保存时检查原账号版本，更新原 password_hash，增加版本并删除该账号全部 sessions。角色、启停、成员关联和历史业务不变；停用账号不会因为重置被启用。此入口不处理当前管理员本人改密，本人改密后续单独接入。

新增 040 只保存不可改写的账号操作审计及持久回执。账号创建/重置、原成员绑定及审计失败时全部回滚。账号操作与已有角色/启停变更使用同一管理员串行锁，事务中重新核查操作者当前角色与启用状态。列表、历史、回执不返回密码、密码散列、会话或密码指纹；密码仅作为原账号的安全散列保存。编辑框关闭或成功后清空密码，不进入本地草稿。

一个保存标识对应一次凭证操作。已完成标识再次提交只返回原结果，不重新设置密码；更改密码必须新开一次操作。元信息变化重用标识会冲突。为避免在审计中留下密码校验副本，密码不参与回执元信息校验。即使目标后来再次改密，重放旧操作也不覆盖新密码。保存结果不确定时先查本人回执，员工和其他管理员不能读取该操作者回执。

原登录验证后，在创建会话的事务中共享锁定账号，再次核对启用状态和刚验证的密码散列。重置/停用先发生则拒绝旧验证，登录先发生则其会话被随后的重置清除，不留旧密码会话。旧密码格式的散列升级保持兼容。

当前角色仍是原 admin/employee。开通管理员意味着授予现有管理员范围；超级管理员、财务/薪资等独立授权仍是下一项，不将本轮账号表单算作分权完成。没有新建超级管理员默认账户，也没有改动真实云端身份。

累计 142 项自动检查通过：80 项前端/契约、62 项临时本机后端。页面操作核对继续暂停；云端只读预览仅加载新前端模块，仍阻断账号 POST 和私有操作回执。新迁移仅本机临时库验证，未部署。

知识库再次确认仅导航飞书：工作台保存导航必需的标题/分类/链接等元信息，不新增正文编辑器、正文存储或正文同步。

后续更新（041）：账号开通/重置/角色状态已要求独立账号安全授权；普通账号安全管理员只能维护员工。管理员创建/维护/密码重置及敏感授权由当前有效超级管理员处理。新管理员默认无敏感授权，不能通过角色提升取得财务或账号权限。详见 admin-permissions.md。
