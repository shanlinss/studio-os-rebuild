# 当前工作台权限边界与撤权收尾核对

本轮沿用原账号、敏感授权、业务分配、库存店铺范围、会话撤销和审计体系。没有新建权限系统、增加默认授权，或扩大员工/管理员可见范围。无新数据库迁移，当前仍为079。

## 后端读取补漏

原支出写入已经在事务内复核当前财务授权，本轮为旧记账读取统一补上实时账号与授权读取：记账本、支出审计、CSV导出、私有凭证字节及原分类/支出/结算/报销入口均不能沿用撤权前传入的身份对象。账号目录、账号权限变更历史与私人账号开通/密码重置回执也补同样校验。停用账号返回未登录；撤权、角色降级或伪造传入的管理员标记不能恢复权限。

HTTP仍由原会话按每次请求读取实际身份，原授权更新继续撤销目标全部旧会话；本轮没有改掉原CSRF、管理员变更限制、幂等回执、账目审计或财务月结保护。受保护原文件及001–033迁移不变。

## 当前已实现模块交叉核对

新增统一矩阵使用超级管理员、财务、账号安全、薪资、人员、资源、仅实名授权、资源+财务+实名及员工9种身份，核对：记账本、经营总览、月结、支出审计、账号目录、人员历史、薪资、设备历史/采购、独立设备归属、手机卡实名及充值余额。组合授权仍按原规则要求同时具备，单项授权不能替代其他项。

- 财务可读取原财务依据及设备采购金额，但不能因此管理资源或读取实名；手机卡财务仍需要财务与资源共同授权。
- 人员、薪资与账号安全互不替代；普通成员目录保留必要业务关联字段，人员日期/岗位及登录关联依原投影隔离。
- 设备共享目录、本人借还继续沿用原员工范围，不带采购价、凭证、内部说明或设备序列号。资源授权可以看管理资料，不因此获得财务金额。
- 普通运营账号目录不向无资源授权的管理员返回绑定/实际号码与内部说明；交接核对仍只返回必要账号及负责人信息。
- 手机卡普通档案不带实名版本；仅实名授权而没有资源授权仍不能读取卡片实名。
- 私有支出凭证按当前财务授权读取，知道原文件ID或有资源管理权不能下载。
- 明确店铺库存查看范围不授予全局库存、其他店铺数量、内部说明或成本接口。撤销范围后列表返回空范围，旧库存明细返回不可见；只读授权不升级为数量写入。

各业务原有细分验证继续纳入完整回归：本人任务/事项和素材执行、考勤/薪资引用、原设备/样品借还、商品与包材归属操作、财务/资源/实名字段隔离、私人回执以及撤权后的实际服务检查。未新增“按店铺拆分财务授权”等未定义规则。

## 已打开页面与异步读取

API统一观察JSON、附件、工资导出及保存请求的401/403。401清除保存凭据，关闭并清空已打开弹窗、导航和页面缓存，停止详情与资源工作区的读取，释放原附件预览；重新登录后读取当前范围。

读取按访问上下文隔离。上下文变化后，旧请求返回的JSON、克隆响应、附件流、文件体及异步导出结果不再交给新页面。旧请求晚到的401也不能使已经重新登录的新身份退出。开始登录、退出及下班后同样作废旧读取。未确认的保存仍沿用原不确定结果保护，不自动重放写入。

403保留正常“无权访问此项”的语义，不把每次业务拒绝当作退出登录；页面会重核当前身份与库存范围，实际范围变化时再清理并重读。恢复浏览器焦点或页面重新可见时也核对当前授权，不增加定时轮询任务。这在下一次请求、回到页面或收到拒绝时生效，不声称使用了服务器推送。

只读预览仅增加清理模块静态文件，没有新增特权接口、保存能力或暴露写入凭据。

## 本轮边界

这是对当前已开发模块的读取、字段投影和撤权边界收尾，沿用已经确认的岗位/业务/店铺库存规则。新业务或未来扩展仍需使用同样校验，不将本轮当作尚未开发功能的权限验收。

按用户要求，实际浏览器页面操作核对和集中桌面UI修整仍暂停。只做桌面网页；云端未写入、未迁移或部署。
