# 幸运发财树：桌面UI首轮落地（2026-11-05）

## 用户确认的视觉方向

参考BoardUI的组件层级及Notion的留白/内容组织，品牌主色改为小红书红。用户提供幸运发财树Logo后，使用其星星、飘带树、笑脸与完整底部“幸运发财树”字标，浅红底座配原黑白图形，不继续使用旧S标识。原上传图片保持不变，网页使用透明背景整理版本。

本轮落实的是全站公共视觉基础与每日工作台首版，不代表29个页面均已完成细节修整或所有业务流程已实际验收。

## 实现范围

- desktop-theme.css集中定义品牌/交互/背景/文字/边框/状态的颜色角色及常用字号、间距和控件；主品牌色#FF2442，白字按钮使用更深红#D91B38提高可读性。原底层样式中的灰绿色换成中性灰，保留成功、进行中及不同类型的语义色。
- 桌面侧栏、导航选中、顶部路径、标题、日期筛选、列表行、搜索、表格、表单、弹窗与知识分类共用该基础；约1000px及以上的桌面浏览器保留两列布局，宽桌面使用更充裕的侧栏与右列。不新增移动布局。
- 首页继续“我的工作清单＋右侧经营提醒”。经营提醒仍复用原接口及授权，不改变数量口径；卡片移除大块绿色背景，按实际信息层级呈现。
- 新增原创纸片小角色，以代码原生SVG用于首页空状态、提醒标题；线条、眼睛和红色折角统一。用户Logo始终是品牌标识，小角色为辅助引导。
- 空清单提供添加事项入口；筛选无结果时可清除筛选。原日期、类型、完成状态、保存、原角色权限及业务关系保持。
- 完整Logo用于侧栏与登录页，也作为站点图标；预览及只读代理明确开放新增样式、SVG模块与PNG资源。没有新增组件框架依赖。
