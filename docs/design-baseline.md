# 产品与设计基线

用户于 2026-11-02 再次指定首轮“从今天开始，一件件做好。”首页截图作为设计基线。历史代码包只提供可复用技术能力，不能改变已确认的页面和操作设计。

## 决策依据

1. 用户当前明确指令与后续确认。
2. 《Studio OS 网站地图与功能说明.pdf》确定整体七大中心范围。
3. 本项目已确认的页面、操作及本次首页截图。
4. 旧数据库、连接、接口和通用基础设施作为实现资源；旧界面、模块分组和业务交互不自动成为新需求。

## 首页必须保留

- 浅色背景、绿色强调色、白色工作面板、桌面左侧导航。
- 问候标题“从今天开始，一件件做好。”及辅助说明。
- 日期左右切换和回到今天。
- 添加事项入口。
- 我的工作清单、完成数量及进度环。
- 全部 / 待处理 / 进行中 / 已完成状态筛选，以及搜索与类型筛选。
- 右侧复盘卡片、工作衔接提示。
- 从清单打开详情，保留工作上下文。

上述结构由 `dist/daily-layout.mjs` 单一组件提供。示例版和云端版必须复用同一组件，不能各写一套首页后逐渐偏离。

## 复用技术能力的边界

- 优先使用已有数据库、稳定 ID、连接、登录身份、权限与接口，不重造相同基础能力。
- 接口字段转换在数据适配层完成；字段不足则记录差异，按当前产品需求做必要的兼容扩展。
- 不以“旧库如此设计”为理由擅自简化新页面、改变交互或引入旧界面。
- 只读预览可以暂时禁用新增/完成等写操作，但必须保留已确认的页面结构并说明不可操作原因；这不是删除最终功能。
- 真实数据为空时展示同一页面的空态，不使用示例记录填充；身份范围和服务端权限继续有效。
- UI 细节后续统一调整；当前只推进桌面网页端。
