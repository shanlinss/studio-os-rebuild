# 日常销售、客户退款与平台手续费（069）

入口在记账本的“销售、退款与手续费”。原代码包仅有支出、垫付及报销，未找到可直接复用的收入/客户退款服务，因此新增日常业务记录层，继续使用原店铺 ID、Finance 金额/凭证、财务授权、请求回执、追加历史和共享编辑器。

## 口径与复用

日常销售、客户退款、平台手续费分别记录正数金额，并按各自业务日期归月。合计覆盖筛选的全部有效记录，不限当前 50 条。销售不是正式平台结算收入，也不代表实际到账；本层不生成利润、资金收付、转账或库存变动。客户退款与供应商代发退款分开，后者继续由 068 按原代发成本核对。

手续费可独立登记，也可整笔引用已有支出。引用时核对当前支出版本与金额，保存来源快照；原支出后来修改时标记待复核。可直接进入原支出详情查看凭证，继续复用原私有图片存储及访问控制，不复制凭证或生成新支出。手续费来源核对与原费用不得在未来利润中再算一次；正式来源映射、费用分摊和报表去重将在后续处理。

本层不会把日常销售、正式结算收入和到账金额相加。原支出、报销、采购成本、库存资产和代发成本记录保持原结构，关联支出作废本层核对记录时也不被改写。

## 原销售关联与修正

新销售和手续费选择启用店铺；原店铺停用后，仍可沿用原销售关联登记退款。退款必须引用同店铺有效销售及其当前版本，日期不能早于原销售，全部有效退款合计不得超过原销售金额。退款、销售修正与作废共用原销售的事务锁，防止并发超退或作废后继续挂有效退款。销售金额不能修正到小于已有有效退款，销售日期也不能晚于有效退款。更改销售说明或金额后，旧退款保留原销售快照并提示来源有新版本。

店铺、种类、来源编号、原销售/支出关联固定；可修正日期、金额、说明、备注及核对依据，修正追加版本。作废保留旧版本并退出有效合计；有有效退款的销售不能直接作废。作废不可恢复，来源编号及原支出引用仍保留，避免原单重新录入后重复计入。

同店铺同种类来源编号大小写不敏感唯一，已引用支出只对应一条手续费核对记录。来源编号可用订单号、每日汇总编号或平台费用单号；此规则用于手工记录防重，不替代后续导入预览和平台订单级去重。

## 权限、事务与核对

财务授权可读写，不额外要求资源管理权限。服务端读取时检查当前权限，写入时在请求回放前锁定并复查有效财务授权。普通员工、只有资源权限的管理员及已撤销财务权限的旧身份不能读取或保存。

创建、修正、作废都保存操作者专属回执；同一请求返回原结果，换内容或换目标不能复用。记录、版本、回执同一事务，后段失败不留下部分记录。原始身份、版本和回执均不可改写或删除。列表和历史每页 50 条，合计以整数分计算，大额合计保留整数字符串精度。

当前只在本机验证和迁移；实际页面操作核对继续按用户要求暂停，未写云端。正式结算收入、实际到账、平台报表导入/匹配、费用分摊及月结锁定仍待后续接入。
