# 知识库导航实现与验证

按用户 2026-11-02 补充：不开发草稿多人同步；知识库仅承担分类、查找和飞书文档导航。正文在飞书维护，不设站内正文编辑器或独立编辑板块。

管理员在知识库当前页面展开轻量表单，新增或修改名称、分类、说明、标签和 HTTPS 飞书链接。分类可选择已有值或直接输入新值；员工没有维护按钮。外链直接打开新标签，仍需要对应飞书权限；站内授权不代替飞书授权。不会自动创建、修改或分享飞书文档。

复用 knowledge_assets、knowledge_events、原管理员鉴权、CSRF 与版本控制，无新增表或迁移。新增导航存为原 link 类型。PATCH /api/knowledge/:id/navigation 仅修改导航字段，保留旧文章正文、封面和来源关联。旧结论类型受原数据库约束保护，不直接改成飞书入口；需要另添导航。原学习复盘接口不在本次修改范围。

POST /api/knowledge/navigation 与 PATCH /api/knowledge/:id/navigation 均在入口及业务服务校验管理员。只接收导航字段，不接收 body、角色或来源关系。拒绝非 HTTPS、伪装域名、含账号密码或非标准端口的链接。过期版本拒绝覆盖；保存结果不明时保留表单、停止重试，要求重新读取核对。

验证：52 项前端/接口契约检查、14 项真实后端检查通过（合并本轮附件/拍摄范围）。涵盖管理员保存、员工写入 403、无 CSRF 403、非法链接 400、旧正文及类型保留、版本冲突 409、学习记录不能从导航入口修改。浏览器使用临时 local_admin 添加、改名和改分类，刷新后仍保留；切换 local_employee_a 后只显示查询与外链，不显示维护按钮。

浏览器示例链接仅供本机流程测试，不代表真实飞书文档；未访问外部示例文档。真实云端预览仍只读，新接口尚未部署到服务器。
