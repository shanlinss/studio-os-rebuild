# 经营总览与月度手工确认收入（071）

用户明确公共费用不分摊到店铺，并选择“每月手工确认收入，填写已扣客户退款、未扣经营成本的金额”。入口位于记账本主操作区“经营总览”。

## 收入确认

沿用原店铺 ID。每家店每月确认经营收入，填写金额、来源编号和依据。金额允许明确的零及负数；未确认保持未知。日常销售/客户退款只供对照，不叠加到确认收入，也不再从确认收入扣客户退款。这里的人工经营收入确认不代表正式平台结算单导入或现金到账。

修正追加版本，支持撤回。撤回保持原确认金额，原记录和依据保留；撤回后，有业务来源的店铺显示收入待确认，无其他业务的店铺不以零收入计入总览。请求回执按操作者、店铺和月份隔离；版本竞争、变更请求内容、无当前有效确认却撤回都返回冲突。收入确认不写原账本、库存或资金流水。

## 专属成本与公共费用

- 店铺专属成本由明确归属的运营支出、实际商品已售成本、代发净成本和独立手续费组成。公共运营费用只在工作室汇总扣一次。
- 已引用支出的手续费不再增加一笔成本，采用原支出日期和金额。关联来源版本、用途或店铺不一致时提示核对；跨月费用引用也不把同一支出在新月份再扣一次。
- 原采购款仍标为运营费用、且关联商品/包材/设备采购来源时，暂停相关结果，避免与采购成本或资产重复扣减。库存采购与预付款单独列示。
- 商品成本直接复用原移动平均引擎及采购/期初/退货来源，不另建一套算法。按业务店铺归集；跨月商品退货回冲原发货成本。内部调拨和分账复制不构成经营成本。每个店铺先按精确分数累计各 SKU 再到分展示，总览合计以各店铺显示金额为准，不把逐行显示的舍入单价带回计算。
- 代发采用最新实际成本版本及供应商实际退款，退款按实际退款月份回冲；参考估算不冒充实际成本。
- 有缺失成本、估算成本、未核实手续费来源或店铺归属时，对应店铺专属成本合计及利润显示待核对。未归属支出不能当作零成本；公共/未归属来源尚未核实时，工作室利润保持待核对。
- 072 已接包材领用金额、其他出库/盘点费用归属；缺原成本或未明确归属时提示来源，不自动填零。转样品保留为资产，不扣利润；073 已接原样品盘亏/报废的资产成本结转与明确费用归属；成本或归属不足时待核对，借还不计费。工资等其他成本仍需按实际来源核实录入。当前是已录入来源的经营测算，不是成本完整性确认或月结锁定。

## 店铺数量与历史

按该月份收入确认或业务来源列出店铺，不按今天的启用店铺数量分摊费用。新建但没有本月来源的店铺不自动算零收入；停用店铺的历史收入和业务仍显示。可选店铺列表保留历史店铺，便于补录历史月份。店铺新增、启停不会改写公共费用或已保存收入。

## 计算关系

店铺利润测算 = 月度确认收入 − 已接入且核实的专属成本。

工作室利润测算 = 各店铺利润合计 − 公共运营费用。

用户例子作为验收：三家店确认收入合计10万元，专属成本分别1万、2万、3万元，店铺利润合计4万元；再扣公共费用2万元，工作室利润测算2万元。未归属或缺失数据会阻止结果，不以零替代。

## 边界和验证

查看与确认需要财务权限，普通员工和只有资源权限的管理员不可访问。当前权限在写入回放前重新检查；金额采用整数分，计算与查询不触碰原库存/账本。总览一次可重复读事务读取所有来源，避免查询期间看到不同版本的半套结果。收入历史每页50条，来源索引及待核对示例最多显示50条，计数和合计仍覆盖全量来源。

复用 063–070 原来源、费用归属与报销结构。071 仅新增月度收入依据和私人回执；库存成本查询提取成共享只读函数，保留原 SKU 核对接口。原33份迁移继续保持原校验值。

自动验证覆盖用户例子、跨SKU精度、重复费用排除、跨月商品和代发回冲、店铺新增/停用、收入零/负值、撤回、并发冲突、失败回退、历史分页及权限。实际页面操作核对继续按用户要求暂停，未部署云端。

## 实际资金对应（074）

总览新增原收入对应到账的核对入口；到账、公司付款和原报销付款在独立资金列表列示。跨月/分次对应不叠加经营收入，不改变成本或报销余额。收入减累计有效对应的差额只用于核对，不自动认定退款、手续费或未收款。详见 cash-correspondence.md。
