# 样品资产、损耗与报废成本（073）

用户明确：商品转拍摄样品先保留资产，不立即扣经营利润，损耗或报废时再记费用。公共费用只在工作室汇总扣一次，不分摊到店铺。

## 复用与入口

复用033样品档案、原入库/盘点/借还事件、039商品转样品双边关联，以及065–072商品成本来源。没有新建数量库、样品采购单、费用单或报销单。样品目录补出原盘点入口“盘点／报废”：填写仓内实际可借剩余数，借出未归还的样品不在此扣减。借出样品应先核实实物归还，再按实际报废盘点，不能用盘点结清借用。

记账本“经营与成本明细”增加“样品资产与损耗”，从经营总览的待核对项也可进入原样品成本记录。财务可核对损耗/报废及公共/明确店铺归属；补直接入库或盘盈成本还需资源授权。普通数量接口和员工借还记录不返回成本金额、费用依据或财务历史。

## 资产和费用

商品转入自动承接原商品出库的精确成本，不接受第二次手填。独立样品入库或盘盈以该次实际增加件数补总成本，明确零元与缺失依据分开。原样品档案作为成本池，每次增加后更新移动平均成本；借出与归还排除费用与成本数量重放，所以借用中资产仍计入。

样品原盘点负差额按减少当时的资产成本结转。财务明确损耗/盘亏或报废及公共/店铺专属归属；成本不可在费用表单里任意改金额。归属或原成本缺失时保留待核对，并阻止不完整利润。资产余额以截至所选月末的全部实际增加与损失核对，包括借出未还件数；当月商品转入额与剩余资产余额分别显示，不相互替代。

成本在内部保留精确分数，逐行显示到分不会影响后续平均值。费用汇总先按公共或店铺合计再舍入。资产全部耗尽后新到货可建立新的已知成本，旧损耗缺成本仍保留待核对。登记日按原事件的北京时间归月，不新增回填日期；这里是动态经营测算，未月结锁定。

## 变更、防重与追溯

原商品成本更正会动态重算样品资产。损耗保存时记录当时成本来源标识与精确成本，原依据变化后须重新核对损耗，不能静默确认旧利润。直接入库引用原库存采购支出时，保存原版本；原支出变更后提示核对。

损耗可引用同一业务月、同归属/运营用途且金额一致的整笔原支出，引用后只计原支出一次。不自动创建资金或报销。样品成本和072库存成本通过同一支出锁互查独占引用，同一整笔支出不能挂到两处；本层引用解除后仍保留原独占事实。与有效手续费来源冲突时保持待核对，不确认重复费用后的利润。

新迁移只增加成本依据/归属版本、整笔原支出引用和私人回执。每次更正追加历史，保留原事件快照、成本标识、原支出版本、依据、原因、操作者与时间。并发版本和成本标识冲突均须重读；同一请求回放返回原结果，权限在回放前重新核查。后段失败回滚全部成本写入，不改变原数量。明细/历史每页50条，资产及费用合计覆盖全量来源。
