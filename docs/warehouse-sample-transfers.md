# 产品转为拍摄样品（2026-11-03）

管理员从产品库存详情选择“转为拍摄样品”，填写实物数量和原因，核对规格及一件对一件关系。首版只支持已登记期初、启用且有余量的件／个产品；不把箱、包、套或小数直接换算成样品。

可新建原样品档案，也可按名称/位置检索同产品的启用样品，目标每页 50 条。已有目标同时检查样品版本，保留名称、说明、保管人、位置和既有借用。首次关联须人工核对规格；绑定后该样品只能接收同一个来源库存项目，避免混规格。不同来源须使用各自样品档案。

同一个服务端事务锁定来源与原样品，检查版本、状态和余量，扣商品库存，追加原出库流水，增加原样品可借库存及原入库事件，保存双方关联及持久回执。任意后段失败全部回滚，包含新注册的样品和首次绑定；重复请求返回原标识，不重复增减。嵌套目标字段顺序不影响请求校验。客户端响应不确定时先核对本人回执。

商品详情有“转样品记录”，样品目录有“转入记录”。两侧读取同一关联事实，显示转出/转入数量、双方前后结余、当时名称、原因、操作者及时间；改名不改变旧快照。记录每页 50 条，员工无仓库转入历史读取权限，原有本人样品借还流程继续使用。

039 仅增加不可改写的来源绑定和双边关联表。原库存余额、产品、样品、身份、出库和样品入库事件继续共用；原样品登记和入库只提取事务内公共逻辑。未修改原 001–033 或已提交的 038 迁移。

转出后在样品中借用与归还，归还不自动增加商品库存。当前不提供自动逆向转回，也不允许用普通盘点“依据转样记录纠错”模拟撤销；需按实际双方数量另行核对。订单、采购记账、金额估值及成本利润不由此自动生成。

累计 131 项自动检查通过，含样品入库溢出和事件写入失败的完整回滚、并发与重复提交、跨页读取及只读代理边界。实际页面核对按用户要求暂停，未作页面验收结论。云端未迁移、写入或部署。

073 已接成本桥：转样品自动承接原商品成本、保留样品资产，实际损耗/报废再按原盘点负差额计费。借还不产生费用，也不自动转回商品库存。详见 sample-cost-evidence.md。
