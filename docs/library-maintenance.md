# 模板、标题与工具维护（2026-11-05）

先核查旧包与现有服务：模板已有保存、来源校验、归档和附件/发布统计；标题已有批次、条目和复制回执；工具已有网址、分类和原审计。本轮复用原 Templates/Titles/Toolbox 的验证、保存SQL与审计，不另建内容表或复制旧资料，原服务文件保持原字节。

## 本轮范围

管理员可以新建/编辑模板（结构、适用产品/场景、说明、标签、评级、参考链接及原素材/已结束实验来源）；新建标题批次、重命名、追加、编辑与移除未使用标题；添加和编辑工具名称、网址、分类和说明。每行标题可以填写“方向 | 标题”，仅填标题时归为未分类。标题单批最多1000条。

三类资料均支持归档/恢复、在用/归档筛选和维护历史。归档保留原ID、正文、附件、引用和已有使用记录；维护前需恢复。已有使用次数的标题不能从本维护入口移除，可编辑或归档批次；编辑保留条目ID和次数。原始接口继续保留，数据库约束阻止通过旧接口修改已归档的正文/条目/附件。

复制按钮仍只复制文字，不伪增使用次数。原模板执行、发布、数据回填和原复制回执继续使用已有机制。本轮不新增模板附件上传、编辑器、批量导入或新的派发流程。

## 底层与历史

追加081，标题批次和工具增加归档标记，新增不可改写维护前后快照及私人回执；模板继续用原 archived 字段。原001–033迁移校验保持。

维护将原服务的事务回调接入同一个外层事务：原内容、原审计、新快照及回执共同提交或回滚。目标版本防止覆盖他人改动，相同操作者/请求标识只提交一次；相同标识改变参数或目标拒绝。回执读取核对操作者、类别与原请求目标，创建请求目标为空。

历史列表每页50条只返回元信息，单独读取某次前后内容；两者均管理员可读。操作者显示当时成员姓名，不把登录名或身份凭证写入历史。此入口开始之前的原事件继续保留，不伪造历史快照。归档后旧引用和读取继续保留。

## 验证与交付边界

见README的最新自动检查总数。覆盖三类原保存复用、历史与原审计、归档恢复、条目ID/次数保留、标题分页与千条上限、并发版本/重复标识、私人回执、角色撤回/CSRF、晚期失败全部回滚以及历史不可改写。只读代理仅开放历史GET和标题范围查询，不开放保存或私人回执。

实际页面操作核对与集中桌面UI修整仍暂停；云端未应用081或部署新接口。本机预览为临时数据环境，下一项核对个人资料可修改范围及飞书知识导航分类/可见范围。
