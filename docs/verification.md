## 已通过的实际浏览器操作

1. 创建素材，保存来源说明和标签；重复标签去重，详情可查看。
2. 从素材创建实验，当前素材默认选中，保存后引用关系保留。
3. 从实验安排事项，工作台出现关联事项，可以从事项详情返回同一实验。
4. 实验再次进入执行事项时复用同一记录，清单中没有重复事项。
5. 完成事项后，在“我的执行记录”中回看；实验不会因事项完成自动结束。
6. 分别保存 A、B 版本的两次观察，保留版本、观察窗口、北京时间、指标名与数值，不覆盖历史。
7. 没有结论时尝试结束实验会提示补充；填写结论后可以保存。
8. 测试结论页直接展示实验室结论，刷新后仍有两次观察和原结论。
9. 浏览器检查无 JavaScript 错误或警告。
10. 归档/恢复素材保留实验引用，已归档素材不能直接发起新实验。
11. 素材搜索、类型与归档筛选，以及实验状态筛选可使用。
12. 日期切换、事项新增与原有本地事项在升级后保留。

## 本机原后端完整链路（2026-11-02）

故事：员工从已确认首页安排本人工作，经原 HTTP API 保存到原 PostgreSQL 表；素材实验先保存想法与参考，再将同一轮次派发到原任务，发布和观察后形成结论。

| 边界 | 证据 |
| --- | --- |
| 新 UI → API | 实际浏览器新增、修改、完成事项，保存后重新读取原记录；计划日期与截止时间保留 |
| API → 数据 | 原后端在临时 PostgreSQL 运行；从 33 个旧迁移升级至 35，旧请求 hash 可重放，版本竞争只成功一个 |
| 数据 → 响应 | 实际完成时间为服务器事实；新时间字段统一 ISO，旧历史没有真实完成时间仍为 null |
| 实验 → 执行 | 创建实验无自动任务；稍后派发写回原任务；重复请求返回原 ID，其他账号的任务不可访问 |
| 发布/回填 → 复盘 | 实际浏览器进入原任务登记发布、回填阅读 0/点赞 3，读取显示其他指标未知，再记录复盘 |
| 结论 → 知识入口 | 原实验结论直接出现在测试结论页，未复制成第二份记录 |

发现并修复：PostgreSQL 时间返回值改为明确 ISO；无执行任务的实验标为待安排；同名执行任务补负责人/账号；个人旧记录缺日期时禁止猜测覆盖；已结束实验的写入口关闭，不再占当前待处理清单。

自动检查和浏览器角色结果以本轮最终运行记录为准。仅为隔离员工账号测试，不是实际员工云端账号验收。真实云端仍未写入。

补充实际浏览器：管理员退出后恢复登录页，隔离员工 A 再次登录，只看到本人执行事项，无法看到管理员发布记录；已结束事项明确展示结束状态，未提供继续发布入口。新导航保留员工本人考勤/个人资料，隐藏管理入口。浏览器未捕获 JavaScript 错误。
