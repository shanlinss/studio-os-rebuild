# 每日工作台 · 第一轮页面验证

## 本轮目的

让用户通过可操作页面判断视觉感觉、信息重点与日常操作是否符合工作习惯。

## 页面结构提案

- 左侧为团队工作区和模块目录，未开发模块清楚标注。
- 主区域为日期、待完成进度、事项筛选与事项列表。
- 查看事项时打开右侧详情，保留列表上下文。
- 次要区域展示当日工作建议与原型说明，不伪造实际统计。

## 可操作验收

- 新增事项，输入标题、类别、日期和说明后保存。
- 打开事项详情，修改说明，切换状态。
- 按全部、待处理、进行中、已完成筛选，并搜索事项。
- 切换日期，查看对应日期的事项；空结果展示空态。
- 刷新页面后保留本浏览器修改。
- 取消弹窗不保存，Escape 可关闭，键盘可访问主要控件。
- 窄屏能查看事项并使用新增和详情。

## 本轮不代表已完成

登录、服务端权限、多人同步、真实素材测试数据、财务、附件、生产部署和历史数据迁移均未接入。浏览器本地保存只适用于原型体验，不用于正式团队数据。
