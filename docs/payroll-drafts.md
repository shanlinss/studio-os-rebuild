# 薪资授权、基础工资和工资草稿首版

入口：考勤页 → 基础工资与工资草稿。保持已确认的桌面布局，不增加移动端范围。仅当前超级管理员或明确获得 payroll 授权的管理员可访问；员工首版不提供个人工资单。

## 权限和复用

财务访问、账号安全与薪资授权分别管理。普通管理员即使已有财务授权，也不能查看工资、工资历史或私人回执；只有薪资授权也不能读取财务账或维护账号。新权限仍由原超级管理员授权，修改原因、版本保护、审计和撤销旧会话沿用原流程。

047仅扩展原权限约束，并追加salary_versions、payroll_drafts及私人回执。旧管理员不自动获得新授权，已明确设置的超级管理员继续拥有所有敏感能力。旧33版身份/成员和已实现考勤继续复用，旧底层没有工资生效版本或工资草稿，因此没有重建身份、数据库连接或平行打卡台账。

薪资入口对未授权身份隐藏，接口及服务方法均检查授权；读写事务再次读取实际权限，过期服务身份不能绕过撤权。云端只读预览仅转发白名单读取且继续依赖原后端鉴权，不转发金额修改和私人回执；旧云端没有新接口时明确失败。

## 基础工资生效版本

- 按成员登记生效月份、参考月基础工资和必填原因。金额使用人民币整数分，允许明确登记0，区别于尚无工资版本。
- 每次登记追加不可改写的版本。查询月份选择不晚于该月的最近生效月，同一生效月取最后登记的版本；未来生效版本不影响早期月份。
- 同一生效月重新登记用于纠正原值，旧值、操作者和时间继续保留。并发登记需要匹配该员工最新登记版本。
- 首版按月份生效，不自动制定月中工资变更、入离职折算、请假扣款、社保或个税规则。

## 工资草稿

仅当该员工对应月份有来源一致的有效考勤锁定版本，且存在生效基础工资版本时，允许建立草稿。直接调用接口同样检查所传锁定ID、工资ID、来源一致及最新草稿版本。

草稿人工确认本次基础金额、奖金、补贴、其他调整（可负）、必填金额依据，并明确勾选已核对金额与引用版本。参考月薪可预填，但不直接判定为本月应发；月中入职等特殊情况由授权操作者确认基础金额。合计仅为四项相加，不读取迟到次数自动扣钱，也不自动生成绩效或税费。

所有金额精确到整数分，不隐式四舍五入。单项非负金额上限为10,000,000,000元，其他调整在其正负范围内，合计须非负且不超同上限；此为输入范围，不代表业务预算。没有多币种换算。

修改追加新草稿版本，旧金额、引用的考勤/工资版本、说明、操作者与时间不可改写。草稿列表与历史均只限薪资授权，历史每页50条。

日历、补卡、请假或人员适用资料变动导致考勤来源变化，考勤重新开放/重新锁定，或该月生效工资版本变化，都会使原草稿提示来源变化。重新核定考勤后，授权人员需重新核对每项金额并保存新草稿，系统不会悄悄刷新旧金额。

数据读取、版本核对、新版本和持久回执在同一可重复读事务保存。事务读取之后提交的业务变动属于后续变化，再读会提示过期。同一请求只保存一次，跨操作者不能读取对方回执；回执失败全部回滚。

## 边界与下一步

本次实现员工草稿准备，未实现工资确认/锁定、Excel导出、支付或财务记账。管理员不打卡情况下的工资流程、离职生效范围和员工工资单可见范围仍需在对应范围继续处理，不把当前员工草稿计作全部工资需求完成。

下一项继续工资确认与锁定、导出，并在确认时再次核对引用版本；发薪记账仍应与确认分开。未明确的扣款、绩效和税费公式不自行设定。
