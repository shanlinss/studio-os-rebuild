# 工作室资源：设备归属、交接核对及手机卡固定资费

沿用原设备、借还、交接、成员、运营账号、店铺、手机卡、充值和财务支出。第079项迁移只追加独立归属、账号核对记录、套餐版本和私人回执，不重新创建资源档案或费用账本。

## 设备独立店铺归属

设备目录显示“归属待确认／工作室公共／店铺专属”。进入设备“设备归属”可明确选择归属和店铺，并填写原因。没有确认过的旧设备保持待确认，不根据主账号、额外账号、使用人或手机卡自动推断。

归属版本独立于原设备借还版本；修改归属不新增设备、不改当前使用人、保管人、原设备状态或其他资源的店铺。版本保存店铺名称快照、操作者、时间和原因，历史50条分页。原店铺停用后可保留原归属，也可清为公共或待确认；不能给另一设备新选已停用店铺。

## 设备交接与运营账号负责人

原管理员交接仍关闭旧借用、建立接收人原借用，保留实际交接时间、位置、设备状况和原因。新增核对该设备的全部主设备/额外设备账号：名称、当前负责人、关联类型、是否停用及账号版本。这里不返回账号号码或其他私密资料。

每个账号默认保留原负责人；管理员勾选的账号才同步为接收人。有关联账号时必须明确确认整体负责人安排。已停用账号保留原负责人，不允许在此次交接中同步。没有关联账号时仍兼容原交接流程。

保存重新核对全部关联集合、账号版本和关联类型。预览后账号增删关联、负责人或资料版本变化时，整次交接被拒绝，必须刷新后核对。原账号维护与交接使用同一事务协调，避免同时保存使核对失效。

勾选同步改变的是原运营账号的负责人，不是另建一份“设备负责人”；账号关联其他设备时也仍使用该同一个原负责人。借用、设备归属、账号店铺、手机卡使用人和手机卡实名不随之自动改动。保留原任务和历史交付，不将旧任务批量转给接收人。

交接、原借还、所选账号更新、原账号审计、交接核对前后快照和私人回执在一个事务中。任何一步失败全部回滚；交接历史列出每个账号“保留／同步”及前后负责人，原账号历史也保留实际同步变化。

## 手机卡套餐与固定资费

从原手机卡详情进入“套餐与固定资费”。保存套餐名称、每周期固定金额、周期（每月／每年／一次性／待确认）、可选月扣费日、生效日期、流量/通话等说明及变更依据。

金额留空表示待确认，明确填写0表示零元。月扣费日1–31，仅每月套餐可填写；若当月不足该日，资料口径按当月最后一天理解，本轮不生成扣费任务或自动扣费。原套餐到期、充值提醒继续使用原入口。

页面分别显示当前生效套餐和最近登记版本。当前套餐取截至上海今天已生效的记录，先按生效日期、同日期再按版本取最新；未来版本不提前当作当前套餐。历史保存登记时卡片号码和档案版本，号码后续变化不改历史。修正同一生效日期追加新版本，不删旧版本。原档案的套餐文字和到期日继续保留。

固定资费属于计划资料，不等于实际支出、充值、账户余额或经营成本；不自动记账、不新增原费用、不自动分摊店铺。实际发生的费用继续从原支出、原充值及资金入口登记并核对。

## 授权、并发与本机边界

归属、套餐、原交接和独立历史需要实时资源管理授权；财务权限本身不能查看新资源维护入口，实名仍需要原独立授权。设备基本目录继续沿用原员工查看范围，新增归属不带采购、身份或凭证资料。

保存检查原设备/卡片档案版本和本模块版本，使用操作者私有幂等回执；并发只有一个后继版本。历史与核对记录不可改写。只读预览只开放声明的GET和静态模块，不转发保存或私人恢复请求。原001–033迁移校验保持，不改原数据库连接或新建云数据库。

云端未迁移、未部署、未写入。按用户要求，实际浏览器操作核对和桌面UI集中修整仍暂停，不做移动端优化。

## 本机自动验证

新增后端覆盖：独立设备归属/停用店铺保留、关联资源不变、完整交接核对与默认保留、选择同步、原账号审计、过期关联/版本、停用账号、并发交接、晚失败回滚、明确零/未知/未来套餐、不生成充值或费用、私人回执、50条以上历史、原档案版本、CSRF、授权撤销和不可改写历史。前端覆盖契约、核对默认值与确认、编辑器、只读入口和维护按钮范围。
