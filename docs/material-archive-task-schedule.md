# 素材归档与内容执行改期

本轮处理日常运营清单的前两项。复用原素材、附件、领取、计划轮次、任务、发布和回填记录；不复制素材或另建任务，不改变已确认首页布局。模板/标题/工具维护、个人资料修改范围及知识导航分类/可见范围仍待后续，知识库继续只导航飞书。

## 素材归档与恢复

素材收集箱增加“在用／已归档／全部”筛选，默认在用。管理员从素材详情填写原因归档或恢复，员工保留原收集、在用资料编辑和已共享资料读取范围。归档是共享资料整理操作，不给员工新增团队归档权限，也不新增敏感授权。

归档仅改变独立状态，不把原测试状态改成淘汰或有效，不删除原素材、店铺关联、观察、附件、实验引用、任务引用和领取记录。归档后仍能从原任务/历史打开素材、预览和领取原附件；已安排的原任务继续发布和回填。

新实验/新轮次的参考素材选择隐藏已归档素材；拍摄项保留自己的旧归档引用，但不能为另一拍摄项新选归档素材。本机草稿保留原归档素材ID并允许回看，新草稿选择中不列归档素材；不增加多人同步。

后端同时保护新增计划、任务、模板、拍摄、拆解及候选的归档来源引用，不能绕过选择器直接提交。已有引用的正常完成/交付不被阻断。归档期间不能改原素材内容、店铺关联或增删附件，需先恢复再编辑。归档/恢复产生过历史的素材不能通过旧删除入口抹去历史。

归档和新引用/编辑按原素材锁协调，保存检查当前素材版本；归档与恢复保留独立历史版本、原素材快照、操作者、时间、原因和私有幂等回执。历史50条分页，操作者显示成员名称或角色称谓，不向员工额外返回管理员登录名。原materials.ts保持原字节，通过附加读取适配和数据库保护复用其保存/附件能力。

## 内容执行改期

从原内容执行事项详情进入“调整日期”，管理员填写新日期与原因；留空明确表示未排期。只允许尚未结束、尚有未完成发布目标的publication事项；已结束实验、原测品安排产品已停用、已完成发布目标、拍摄或动作事项不能从此入口改期。拍摄继续沿用原拍摄需求的交付日期。

每个原任务新增独立排期覆盖和版本，默认仍继承原轮次计划日期。改期只影响选中的原任务：不改原轮次日期、不移动同轮其他成员或账号、不改变目标数量与任务ID，也不改已发布、回填、实际完成时间或执行要求。部分已发布时，调整的是这项工作剩余执行的安排，已发生事实继续保留。

当前日期用于每日工作台、执行列表、内容日历和详情；原轮次仍显示原计划日期，变更历史保存前后日期及当时事项摘要。明确清空日期不会被原轮次日期自动填回。改期不创建发布、不算作完成，不增加日常产出计数。

保存锁住原任务，重读当前发布进度、实验/产品状态和排期版本，保留私有回执。并发修改只有一个后继版本，保存失败时日期和历史一起回滚。员工仅能读取当前分配给自己的原事项改期历史，其他人的ID不能越过原业务归属；管理员角色变化后重新检查身份。
