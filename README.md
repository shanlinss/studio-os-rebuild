# Studio OS · 重新开发

服务于 4 人小红书电商运营团队的内部工作台。

## 项目依据

用户于 2026-11-02 指定《Studio OS 网站地图与功能说明.pdf》为整体规划，七大中心完整保留。见 [原文与来源校验](docs/planning-source.md)、[页面清单与实现进度](docs/roadmap.md)。

仅开发桌面网页端；UI 细节后续统一调整。

## 云端只读联调

现有云端后端已完成首轮接口读取核对。保持 SSH 通道和原工作台登录，运行 `npm run dev:cloud`，打开 `http://[::1]:4174/`，使用新界面读取已有素材、实验、产品、拍摄、执行安排、资源、知识及管理资料。没有云端保存、派发或删除操作。详见 [接入范围与验证](docs/cloud-readonly.md)。

下面的原型体验与云端数据分开。

## 当前可体验

- 今日工作：新增、筛选、完成、编辑说明、返回关联实验。
- 我的执行记录：同一事项数据的历史视图；新完成事项记录实际完成时间。
- 素材收集箱：名称、类型、标签、来源链接、观察说明、编辑、归档与恢复。
- 素材实验室：引用素材、想法和版本、计划与进度、安排执行、观察记录、结论。
- 测试结论：直接引用实验记录，避免重复维护。
- 上述为示例版范围；云端版七中心的 29 个入口均已有对应页面，具体可用范围见页面清单。

这是浏览器本地交互原型，不是正式多人系统。初始记录为示例；新增修改保存在当前浏览器。可从今日工作的“本轮体验范围”导出备份。不要在本原型中保存真实财务或凭证。

## 本地预览

无需安装依赖。在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173 。

## 原后端完整联调

`npm ci` 后运行 `npm run dev:integrated`，在 `http://127.0.0.1:4178/` 使用隔离测试账号验证真实保存。它创建全新的本机临时库，退出后清理，不连接云端。`npm run test:backend` 验证原后端、迁移与角色边界，详见 [后端复用与兼容](docs/backend-compatibility.md)。

已跑通本人事项新增/编辑/完成/执行记录，以及实验先记录、再派发、发布回填、复盘和结论。原首页与七中心设计保持。
